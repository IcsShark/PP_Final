## Commands (every timing job: run -c 12, whole node, regardless of threads)
prep : run -c 12 -- bash scripts/exp/e4_prep.sh GRAPH
         gzip -dc raw/X.gz > tmp/X.txt; bin/convert tmp/X.txt -o OUT/X.csr <convert-all.sh args> --emit-wel tmp/X.wel
         (synthetic: bin/gen <gen-synthetic.sh args> -o OUT/X.csr --emit-wel tmp/X.wel)
         cmp OUT/X.csr REF/X.csr
         gapbs/converter -f tmp/X.wel -w -b OUT/X.wsg          (-w keeps weights; no -s, edges stay directed)
sweep: run -c 12 -- bash scripts/exp/e4_sweep.sh GRAPH
         bin/sssp -g REF/X.csr -a delta-omp -d 64,...,262144 (grid2896: ...,16777216) -t 12 --sources 1 --seed 42 -r 3 -q --verify --csv sweep/X.csv
run  : run -c 12 -- bash scripts/exp/e4_run.sh GRAPH T DELTA
         bin/sssp -g REF/X.csr -a delta-omp -d DELTA -t T --sources 4 --seed 42 -r 3 --verify --csv raw/X_tT_dD.ours.csv
         for each source S:  OMP_NUM_THREADS=T gapbs/sssp -f tmp/X.wsg -d DELTA -r S -n 3 -v   (.wsg staged to node-local tmp)
driver (login node; submits the jobs above one at a time; full log in logs/driver.log), in this order:
         bash scripts/exp/e4_all.sh NY CTR USA OK kron23 urand23 grid2896
         run -c 12 -- bash scripts/exp/e4_check_ref.sh        (-> ref_check.log)
         bash scripts/exp/e4_all.sh LJ
         bash scripts/exp/e4_suggested.sh                     (spec 4.5, Delta=50000 on NY/CTR/USA)
iters: run -c 12 -- bash scripts/exp/e4_iters.sh GRAPH     (GAPBS -l iteration count at the best Delta, t=12)
OMP environment: only OMP_NUM_THREADS (GAPBS); ours sets threads with -t. No OMP_PROC_BIND/OMP_PLACES.
ours schedule: bin/sssp default (--sched dynamic,64, --variant all, --filter pop).

## Deviations from docs/E4-experiment-spec.md
- raw/ read from $HOME/pp_data/raw (own md5-verified download): the shared raw/ is not readable by this account.
- outputs in $HOME/pp_data/gapbs instead of the shared $PP_DATA_DIR/gapbs (user's decision).
- .wel and the regenerated .csr written to node-local tmp, not to gapbs/; each .wsg deleted after its
  graph is done. Reason: 10 GB home quota (a USA sweep was lost to 'Disk quota exceeded' and rerun).
- GAPBS converter needs -w (spec 4.3 omitted it; without it the .wsg would be unweighted).
- LJ: the shared reference LJ.csr does not match a rebuild from the md5-checked raw file (20 vertices
  differ, 18 duplicate edges; see ref_check.log from e4_check_ref.sh). User decision: ours and GAPBS
  both run on the regenerated LJ ($E4_OUT/LJ.csr), not on the reference used by E0-E2.
- Delta from a sweep for every graph (spec allows it); the E0 references were clearly not optimal on NY t=12.
- sweep uses -r 3 and the median (spec example: -r 1); grid2896's sweep extends to 2^24 because its
  time still fell at 2^18, the edge of the default grid (2^6..2^18).
- one job per (graph, threads, Delta) to stay under the 30-min QoS limit.
